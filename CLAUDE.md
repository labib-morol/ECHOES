# Echoes — Project Bible

## What this is
An anonymous thought-streaming web app. People release unfiltered thoughts 
onto a dark wall. No login, no identity, no social pressure. Pure emotional 
release. Target audience: 14-28 year olds.

## Core philosophy
This is NOT a social network. It is a release tool. Never add features 
that create social comparison, follower counts, or engagement metrics.
The goal is emotional release, not engagement.

## Tech Stack
- Next.js 14 (App Router, TypeScript)
- Tailwind CSS
- Framer Motion (animations)
- Supabase (database + backend)
- Groq API (mood tagging + moderation, free tier)
- Vercel (hosting)

## Design rules — never break these
- Background: #0d0b09 (warm near-black, never pure black)
- Primary font for thought text: Playfair Display italic
- UI font: Syne (weights 300, 400, 500)
- Accent color: #c47a3a (ember orange)
- No hard borders on cards — use inset box-shadow only
- No public reaction counts anywhere, ever
- No follower counts, no trending, no popularity signals
- Each mood has its own muted color signature
- Cards are absolutely positioned on the wall (scattered, not a feed)
- Mobile fallback: vertical masonry layout
- Subtle grain/noise texture overlay on background (opacity 0.035)
- Cards have a 3px left border in their mood color at 55% opacity
- Card background: rgba(255,255,255,0.06)
- Card padding: 16px 18px (slightly more breathing room)
- Card width: ranges 150–210px based on content length
- Card edge: inset 0 0 0 0.5px rgba(255,255,255,0.1)
- Thought text: Playfair Display italic, 13px, #ccc8c0, line-height 1.75
- Mood tag: Syne 300, 9px, uppercase, letter-spacing 0.12em, mood color at 60% opacity

## Mood system
Moods are AI-generated by Groq — they are freeform, not from a fixed list.
Examples: 'heartbreak', 'late night thoughts', 'missing someone', 
'existential dread', 'tired of it all', 'small joy', 'numb'
New moods can be anything Groq decides based on the thought content.

## Key system
- On post: generate key in format ECHO-XXXX-XXXX (uppercase alphanumeric, 
  exclude 0, O, I, 1 for readability)
- Store only SHA-256 hash of the key in DB — never the raw key
- Key lets the user see their own thoughts softly highlighted on the wall
- Key also shows their private felt count on their own thoughts
- Show key after posting in a styled box — "save this. it's the only way 
  back to your thoughts."

## Felt system
- Each thought has a hollow circle ○ button
- On tap: animates to ember 🔥 with framer-motion scale pulse
- felt_count stored in DB but NEVER shown publicly anywhere
- Only the thought's key-holder sees their felt count privately via key lookup
- One felt per thought per browser session (use sessionStorage)

## Moderation via Groq
- Spam / promotional content → block before posting, return error
- Slurs / hate speech / threats → silent remove after posting
- Crisis / self-harm signals → thought stays, show a quiet helpline 
  line below that thought: "if you're struggling, you're not alone. 
  Kaan Pete Roi (Bangladesh): 01779-554391"
- Dark emotional venting → NEVER touched. This is the entire point.

## Thought expiry
- All thoughts auto-delete after 30 days (expires_at column)
- Query always filters WHERE expires_at > NOW()
- This makes posting feel safer — nothing is permanent

## API routes
POST /api/thoughts    — create a thought (Groq tags mood, inserts to DB)
GET  /api/thoughts    — fetch wall thoughts (excludes expired, excludes key_hash)
POST /api/felt        — increment felt_count for a thought_id
POST /api/key         — hash the provided key, return matching thought IDs
